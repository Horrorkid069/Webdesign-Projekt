# Raï al-Maghrib – neues Wireframe im Design der ersten Website

Dieses Projekt kombiniert:

- die Struktur des neuen Wireframes,
- die dunkle Hero-Fläche, Typografie, Karten, Schatten und Farbwelt
  der zuvor gelieferten Website,
- sowie die Pflichtbestandteile aus dem Regelwerk.

## Texte einsetzen

In `index.html` nach `HIER DEINEN TEXT` suchen.

Die Textpositionen entsprechen den gestrichelten Linien des Wireframes:

1. Was ist Raï?
2. Was ist Marokko? – mittig zwischen den beiden Bildern
3. Amazigh Kultur – links neben dem Video
4. Migration – 2 Identitäten

## Technische Pflichtbestandteile

- HTML5 + CSS3
- externe Stylesheets
- CSS-Kaskade: reset.css -> base.css -> components.css -> print.css
- keine Farben im HTML
- semantische Struktur
- barrierearme Grundstruktur
- Audio
- Video + Untertitel + Transkript
- Canvas 2D
- SVG
- PDF-Download
- Media Queries
- prefers-reduced-motion
- Druckansicht

Vor der finalen Abgabe HTML und CSS zusätzlich über die im Skript
genannten W3C-Validatoren prüfen.
