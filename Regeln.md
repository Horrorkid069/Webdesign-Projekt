# Regeln fuer die Website

Dieses Dokument fasst die verbindlichen Anforderungen fuer die Website zusammen.

## Grundregeln fuer HTML und CSS

1. Alle Farben der Website bleiben im CSS und duerfen nicht direkt im HTML-Code stehen.
2. Es darf kein CSS im `head` des HTML-Codes stehen.
3. Die CSS-Kaskade soll klar erkennbar sein.
4. HTML und CSS muessen sauber getrennt bleiben.
5. Alle HTML- und CSS-Dateien muessen valide sein.

## Anforderungen an die Website-Struktur

1. Die Gruppen-Startseite wird mit XHTML und CSS 2.1 umgesetzt.
2. Jedes Gruppenmitglied erstellt eine eigene HTML5-Seite mit CSS3.
3. Jedes Gruppenmitglied verwendet eine eigene, saubere Ordnerstruktur, zum Beispiel fuer Assets, CSS und Medien.
4. Alle Seiten sollen semantisch korrekt aufgebaut sein.
5. Die Website soll barrierearm gestaltet werden.

## Pflichtinhalte pro Einzel-Seite

1. Es muss ein selbst erstelltes Audio-Element eingebunden werden.
2. Es muss ein selbst erstelltes Video-Element eingebunden werden.
3. Es muss ein selbst erstelltes Canvas-2D-Element eingebunden werden.
4. Es muss ein selbst erstelltes SVG-Element eingebunden werden.
5. Es muss ein selbst erzeugtes PDF verlinkt werden, das ueber die Website heruntergeladen werden kann.

## Gestaltung und Konzeption

1. Fuer die Seiten muss ein Wireframe erstellt werden.
2. Das Wireframe soll mindestens zwei Leitfarben enthalten.
3. Das Wireframe soll Abmessungen und verwendete Fonts festhalten.
4. Designentscheidungen sollen bewusst und konsistent umgesetzt werden.

## Technische Qualitaet

1. Die HTML-Struktur soll moderne semantische Elemente sinnvoll verwenden.
2. Medieninhalte wie Audio, Video, Canvas und SVG sollen technisch korrekt eingebunden werden.
3. Responsive Anpassungen sollen sinnvoll ueber Media Queries umgesetzt werden.
4. Zusaetzliche Accessibility-Features sind sinnvoll, zum Beispiel geeignete Attribute und klare Strukturierung.

## Sinnvolle Zusatzoptionen

1. Interaktive Canvas-3D-Inhalte koennen die Seite erweitern.
2. Dynamisch erzeugte PDFs sind eine moegliche Zusatzleistung.
3. Erweiterte Accessibility nach WCAG ist eine sinnvolle Zusatzleistung.
4. Dezente CSS3-Animationen koennen die Benutzererfahrung verbessern.

## Abgabe

1. Die Abgabe erfolgt als ein ZIP-Archiv mit dem Gruppennamen.
2. Das Handout muss einmal in gedruckter Form und zusaetzlich als PDF im ZIP vorliegen.
3. Die Abgabe muss einen Tag vor der Praesentationsleistung erfolgen.
